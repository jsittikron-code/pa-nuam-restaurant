# ระบบร้านอาหาร "ป้านวม" 🍳

ระบบรับออเดอร์ + จอครัว + แคชเชียร์ ทำจาก HTML/CSS/JavaScript ล้วน
**ไม่ต้องติดตั้งอะไรเลย ไม่ต้องมีอินเทอร์เน็ต ไม่ต้องมีเซิร์ฟเวอร์**

---

## 1. วิธีเปิดใช้งาน

### แบบง่ายสุด (ใช้งานจริงได้เลย)
ดับเบิลคลิกไฟล์ **`index.html`** → เปิดในเบราว์เซอร์ Chrome / Edge

| ไฟล์ | ใช้ทำอะไร | ใครใช้ |
|---|---|---|
| `index.html` | หน้าสั่งอาหาร (เมนู + ตะกร้า) | ลูกค้า / พนักงานหน้าร้าน |
| `kitchen.html` | จอครัว + แคชเชียร์ + ยอดขาย | ในครัว / เจ้าของร้าน |

เปิด **2 แท็บพร้อมกัน** ได้เลย — สั่งจากแท็บซ้าย ออเดอร์จะเด้งขึ้นแท็บขวาภายใน 3 วินาที พร้อมเสียงเตือน 🔔

### แบบเปิดจากมือถือในร้าน (ให้ลูกค้าสแกนสั่งเอง)
เปิด Command Prompt ที่โฟลเดอร์นี้แล้วพิมพ์:

```
python -m http.server 8000
```

จากนั้นเปิดในมือถือที่ต่อ Wi-Fi เดียวกัน: `http://<ไอพีเครื่อง>:8000`
(ดูไอพีด้วยคำสั่ง `ipconfig` → IPv4 Address)

## 2. ขั้นตอนการทำงานของออเดอร์

```
🟡 ออเดอร์ใหม่ ──เริ่มทำ──▶ 🔥 กำลังปรุง ──ทำเสร็จ──▶ ✅ พร้อมเสิร์ฟ ──เก็บเงิน──▶ 💰 เสร็จสิ้น
```

- กดปุ่มบนการ์ดในหน้า `kitchen.html` เพื่อเลื่อนสถานะทีละขั้น
- **ยอดขายจะนับเฉพาะบิลที่ถึงขั้น "เก็บเงิน" แล้วเท่านั้น** (บิลที่ยังทำอยู่ไม่นับ)
- 🖨️ = พิมพ์ใบเสร็จ (สลิป 80 มม.) · 🗑️ = ยกเลิกบิล
- ⬇️ ออกรายงาน CSV = ได้ไฟล์เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน

## 3. แก้ราคา / เพิ่มเมนู — แก้ที่ไฟล์เดียว

เปิด **`menu-data.js`** ด้วย Notepad หรือ VS Code

### แก้ราคา
หาบรรทัดของเมนูที่ต้องการ แล้วแก้ตัวเลขหลัง `price:`

```js
{ id:1, cat:'ไก่', price:80, th:'กะเพราไก่ไข่ดาว', ... }
                        ▲ แก้ตรงนี้
```

### เพิ่มเมนูใหม่
1. เอารูปใส่โฟลเดอร์ `img/` (ตั้งชื่อ `20.jpg`)
2. เพิ่มบรรทัดต่อท้ายรายการใน `window.MENU`:

```js
{ id:20, cat:'หมู', price:75, th:'ข้าวหมูกรอบ', en:'Crispy Pork Rice',
  cn:'脆皮猪肉饭', img:'img/20.jpg', hot:false },
```

> `id` ห้ามซ้ำกับเมนูอื่น · `cat` ต้องตรงกับหมวดใน `window.CATS` · `hot:true` = ติดป้าย "ขายดี"

### แก้ข้อมูลร้าน / เวลาเปิด-ปิด / ค่ากล่อง / จำนวนโต๊ะ
แก้ในบล็อก `window.SHOP` ด้านบนสุดของไฟล์เดียวกัน

```js
phone:'082-641-4370',    // เบอร์โทร
open:'07:00', close:'15:30',  // เวลาเปิด-ปิด (โชว์สถานะอัตโนมัติ)
tables:12,               // จำนวนโต๊ะ
boxFee:5,                // ค่ากล่องต่อ 1 กล่อง (คิดเมื่อสั่งกลับบ้าน)
addons:[ ... ]           // ตัวเลือกเสริม เช่น เพิ่มไข่ดาว 10 บาท
```

## 4. ข้อมูลถูกเก็บไว้ที่ไหน

เก็บใน **localStorage ของเบราว์เซอร์เครื่องนั้น** (key: `panuam.orders.v1`)

- ✅ ปิดเบราว์เซอร์แล้วเปิดใหม่ ข้อมูลยังอยู่
- ⚠️ ข้อมูลอยู่แยกกันในแต่ละเครื่อง/แต่ละเบราว์เซอร์ ไม่ได้ sync ข้ามเครื่อง
- ⚠️ ถ้ากด "ล้างข้อมูลการท่องเว็บ" ข้อมูลออเดอร์จะหายไปด้วย

**แนะนำ:** สิ้นวันให้กด **⬇️ ออกรายงาน CSV** เก็บไฟล์ไว้ก่อนล้างข้อมูล

> ถ้าอยากให้หลายเครื่องเห็นข้อมูลชุดเดียวกัน ต้องเปลี่ยนไปใช้ฐานข้อมูลจริง
> (เช่น Python + FastAPI + SQLite) — โครงสร้างใน `store.js` ออกแบบไว้ให้เปลี่ยนได้ง่าย
> เพราะหน้าเว็บเรียกผ่าน `DB.xxx()` อย่างเดียว ไม่ได้ยุ่งกับ localStorage ตรง ๆ

## 5. โครงสร้างไฟล์

```
panuam/
├─ index.html      หน้าสั่งอาหาร (UI)
├─ kitchen.html    จอครัว/แคชเชียร์ (UI)
├─ app.css         หน้าตา/ธีมทั้งหมด
├─ luxe.css        ลูกเล่นภาพเคลื่อนไหวสไตล์ภัตตาคาร (ลบได้ ระบบยังทำงานครบ)
├─ luxe.js         ตัวขับเคลื่อนลูกเล่นภาพ (ลบได้เช่นกัน)
├─ menu-data.js    ⭐ ข้อมูลร้าน + เมนู 19 อย่าง  ← แก้ตรงนี้ที่เดียว
├─ store.js        ⭐ ตรรกะฐานข้อมูล (แยกออกจาก UI)
├─ img/01.jpg…19.jpg   รูปอาหาร 19 รูป
└─ README.md       ไฟล์นี้
```

**หลักการออกแบบ:** แยก _ข้อมูล_ (`menu-data.js`) ออกจาก _ตรรกะ_ (`store.js`) ออกจาก _หน้าตา_ (`index.html` / `kitchen.html`)
แก้ราคาไม่ต้องแตะโค้ด · เปลี่ยนฐานข้อมูลไม่ต้องแตะหน้าเว็บ

## 6. สิ่งที่ระบบทำได้

**หน้าสั่งอาหาร**
- เมนู 19 รายการ 3 ภาษา (ไทย/อังกฤษ/จีน) แบ่ง 6 หมวด
- ค้นหาได้ทั้งชื่อไทย อังกฤษ จีน และชื่อหมวด
- เลือกระดับความเผ็ด 4 ระดับ · ของเพิ่ม (ไข่ดาว/ข้าว/พิเศษ) · หมายเหตุถึงครัว
- ทานที่ร้าน (เลือกโต๊ะ 1–12) หรือกลับบ้าน (คิดค่ากล่องอัตโนมัติ)
- สั่งเมนูเดิม ตัวเลือกเดิมซ้ำ → รวมเป็นบรรทัดเดียวให้อัตโนมัติ
- แสดงสถานะร้านเปิด/ปิดตามเวลาจริง

**จอครัว/แคชเชียร์**
- กระดานคัมบัง 4 คอลัมน์ · เลขคิว · เวลาสั่ง
- ตัวเลขสรุป: ออเดอร์วันนี้ · ยอดขาย · ค้างในครัว · เฉลี่ยต่อบิล
- อันดับเมนูขายดีประจำวัน
- เสียงเตือนเมื่อมีออเดอร์ใหม่ (ปิดได้)
- พิมพ์ใบเสร็จ · ออกรายงาน CSV

## 7. ลูกเล่นภาพ (luxe.css + luxe.js)

ฉากหลังไล่แสงเคลื่อนไหว · ละอองไฟลอยขึ้น · ม่านเปิดร้านตอนโหลด (คลิกข้ามได้) ·
การ์ดเมนูลอยขึ้นทีละใบตอนเลื่อน · เอียง 3 มิติตามเมาส์ · แสงทองกวาดผ่านตอนชี้ ·
คลื่นกระเพื่อมตอนกดปุ่ม · ตัวเลขยอดเงินเด้งเมื่อเปลี่ยน

- **อยากได้แบบเรียบ ๆ** — ลบ 2 บรรทัดนี้ออกจาก `index.html` และ `kitchen.html` ได้เลย
  `<link rel="stylesheet" href="luxe.css">` กับ `<script src="luxe.js"></script>`
- ระบบเคารพการตั้งค่า **"ลดการเคลื่อนไหว"** ของ Windows — ถ้าเปิดไว้ ลูกเล่นจะหยุดให้อัตโนมัติ
- ลูกเล่นทั้งหมดไม่ถูกพิมพ์ลงใบเสร็จ
