# ร้านอาหารป้านวม · PANUAM KITCHEN 🍳

เว็บไซต์ร้าน + ระบบรับออเดอร์ ทำจาก HTML/CSS/JavaScript ล้วน
**ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีอินเทอร์เน็ต** (ยกเว้นฟอนต์)

🌐 **เว็บจริง:** https://jsittikron-code.github.io/pa-nuam-restaurant/

---

## 1. เว็บนี้มี 3 หน้า

| หน้า | ใครใช้ | ทำอะไร |
|---|---|---|
| **`index.html`** | 👥 **ลูกค้าทั่วไป** | เว็บร้าน — ดูเมนู รูปอาหาร ราคา รีวิว ที่ตั้ง (**ดูอย่างเดียว สั่งไม่ได้**) |
| `order.html` | 👔 พนักงานหน้าร้าน | ระบบรับออเดอร์ — เลือกเมนู ความเผ็ด ของเพิ่ม โต๊ะ |
| `kitchen.html` | 👨‍🍳 ในครัว / เจ้าของร้าน | จอครัว ยอดขาย ใบเสร็จ รายงาน CSV |

หน้าลูกค้า **ไม่มีลิงก์ไปหน้าพนักงาน** (มีแต่ตัวหนังสือเล็ก ๆ ท้ายหน้า)
พนักงานควร **บุ๊กมาร์ก `order.html` ไว้เอง**

### วิธีเปิด
- **ดูเฉย ๆ** — ดับเบิลคลิก `index.html`
- **ใช้รับออเดอร์จริง** — เปิด `order.html` และ `kitchen.html` คนละแท็บ **บนเครื่องเดียวกัน**
  สั่งจากแท็บซ้าย ออเดอร์เด้งขึ้นแท็บขวาใน 3 วินาที พร้อมเสียงเตือน 🔔

## 2. ⭐ ใส่รีวิวลูกค้า — แก้ที่ `reviews.js`

**ตอนนี้ยังไม่มีรีวิว** เว็บจะไม่แสดงดาวหรือคะแนนใด ๆ เลย
(ตั้งใจทำแบบนี้ — ไม่ใส่รีวิวปลอมให้ เพราะลูกค้าจริงอ่านแล้วเข้าใจผิดได้ และ Google อาจตีว่าเป็นรีวิวหลอก)

### อยากดูก่อนว่าหน้ารีวิวหน้าตายังไง
เติม `?preview=1` ท้าย URL:
```
https://jsittikron-code.github.io/pa-nuam-restaurant/?preview=1
```
จะเห็นตัวอย่างพร้อมป้ายกำกับชัดเจนว่าเป็นตัวอย่าง — **คนที่เข้าเว็บปกติไม่เห็น**

### ใส่รีวิวจริง
ก๊อปข้อความจาก Google Maps / Facebook มาวางใน `reviews.js`:

```js
window.REVIEWS = [
  { name:'คุณสมชาย', rating:5, date:'2026-07-28', dish:1, source:'Google',
    text:'กะเพราไก่ไข่ดาวอร่อยมาก ไข่กรอบกำลังดี' },
  { name:'Anna W.',  rating:5, date:'2026-07-25', dish:0, source:'Facebook',
    text:'ร้านสะอาด เจ้าของใจดี ราคาไม่แพง' },
];
```

| ช่อง | ใส่อะไร |
|---|---|
| `name` | ชื่อคนรีวิว |
| `rating` | ดาว 1–5 |
| `date` | วันที่ `'ปี-เดือน-วัน'` เป็น **ค.ศ.** เช่น `'2026-07-28'` |
| `dish` | เลข `id` เมนูที่พูดถึง (ดูใน `menu-data.js`) · ใส่ `0` ถ้ารีวิวร้านโดยรวม |
| `source` | มาจากไหน เช่น `'Google'`, `'Facebook'`, `'หน้าร้าน'` |

พอมีรีวิวแล้ว เว็บจะคำนวณให้เองทั้งหมด: ดาวเฉลี่ยบนหน้าแรก · กราฟแท่ง 5–1 ดาว ·
ดาวรายเมนูบนการ์ด · รีวิวในหน้าต่างภาพใหญ่

> ⚠️ ใส่แค่รีวิวที่ลูกค้าเขียนจริงเท่านั้น

## 3. แก้ราคา / เพิ่มเมนู — แก้ที่ `menu-data.js`

### แก้ราคา
```js
{ id:1, cat:'ไก่', price:80, th:'กะเพราไก่ไข่ดาว', ... }
                        ▲ แก้ตรงนี้
```

### เพิ่มเมนูใหม่
1. เอารูปใส่โฟลเดอร์ `img/` ตั้งชื่อเป็นเลขถัดไป เช่น `24.jpg` (รูปสี่เหลี่ยมจัตุรัสสวยที่สุด)
2. เพิ่มบรรทัดต่อท้าย `window.MENU`:
```js
{ id:24, cat:'หมู', price:75, th:'ข้าวหมูแดง', en:'Red Pork Rice',
  cn:'叉烧饭', img:'img/24.jpg', hot:false },
```
> `id` ห้ามซ้ำ · `cat` ต้องตรงกับหมวดใน `window.CATS` (ตอนนี้มี หมู ไก่ เนื้อ ทะเล สุกี้น้ำ ผัก หมูกรอบ) · `hot:true` = ขึ้นในส่วน "เมนูขึ้นชื่อ" หน้าแรก (ควรมี 4 จาน)

### แก้ข้อมูลร้าน
แก้ `window.SHOP` ด้านบนของไฟล์เดียวกัน — เบอร์โทร เวลาเปิด-ปิด จำนวนโต๊ะ ค่ากล่อง ของเพิ่ม
(เวลาเปิด-ปิดใช้คำนวณป้าย "ตอนนี้เปิดอยู่ / ปิดแล้ว" อัตโนมัติ)

ที่อยู่/เบอร์ที่โชว์บนหน้าลูกค้ายังอยู่ใน `index.html` ตรง ๆ ถ้าย้ายร้านต้องแก้ที่นั่นด้วย

## 4. อัปเว็บขึ้นอินเทอร์เน็ต

เว็บใช้ **GitHub Pages** อยู่แล้ว แก้ไฟล์เสร็จแล้วสั่ง 3 บรรทัดนี้:

```bash
git add -A
git commit -m "อัปเดตเมนู"
git push
```

รอประมาณ 1 นาที เว็บจริงจะอัปเดตเอง (ดูสถานะได้ที่แท็บ **Actions** ใน GitHub)

## 5. โครงสร้างไฟล์

```
panuam/
├─ index.html      🌐 เว็บร้าน (ลูกค้า)
├─ showcase.css       หน้าตาเว็บร้าน
├─ showcase.js        เนื้อหา + ภาพเคลื่อนไหวของเว็บร้าน
├─ reviews.js      ⭐ รีวิวลูกค้า      ← แก้ตรงนี้
├─ menu-data.js    ⭐ ข้อมูลร้าน + เมนู ← แก้ตรงนี้
│
├─ order.html         ระบบรับออเดอร์ (พนักงาน)
├─ kitchen.html       จอครัว/แคชเชียร์
├─ store.js           ตรรกะฐานข้อมูลออเดอร์
├─ app.css            หน้าตาระบบออเดอร์
├─ luxe.css / luxe.js ลูกเล่นภาพของระบบออเดอร์ (ลบได้ ระบบยังทำงานครบ)
│
├─ img/01.jpg…23.jpg  รูปอาหาร 23 รูป (สี่เหลี่ยมจัตุรัส 360×360)
└─ README.md          ไฟล์นี้
```

**หลักการ:** แยก _ข้อมูล_ (`menu-data.js` / `reviews.js`) ออกจาก _ตรรกะ_ (`store.js`) ออกจาก _หน้าตา_
แก้ราคาหรือใส่รีวิวไม่ต้องแตะโค้ดเลยสักบรรทัด

## 6. ลูกเล่นภาพในเว็บร้าน

ฉากหลังฮีโร่เป็นภาพอาหารสลับพร้อมซูมช้า (Ken Burns) · หัวเรื่องเปิดม่านขึ้นจากด้านล่าง ·
ทองไหลในตัวอักษร · แถบความคืบหน้าการเลื่อนด้านบน · เนื้อหาลอยขึ้นพร้อมคลายเบลอเมื่อเลื่อนถึง ·
ตัวเลขวิ่งขึ้น · การ์ดยกตัวและซูมภาพตอนชี้ · แถบรีวิวเลื่อนต่อเนื่อง (หยุดเมื่อเอาเมาส์ชี้) ·
แสงนวลตามเมาส์ · หน้าต่างภาพใหญ่เลื่อนซ้าย-ขวาด้วยปุ่มหรือลูกศรคีย์บอร์ด

เคารพการตั้งค่า **"ลดการเคลื่อนไหว"** ของเครื่อง — ถ้าเปิดไว้ ลูกเล่นจะหยุดให้อัตโนมัติ

## 7. ข้อมูลออเดอร์เก็บที่ไหน

เก็บใน **localStorage ของเบราว์เซอร์เครื่องนั้น** (key `panuam.orders.v1`)

- ✅ ปิดเบราว์เซอร์แล้วเปิดใหม่ ข้อมูลยังอยู่
- ⚠️ **แยกกันคนละเครื่อง** — `order.html` กับ `kitchen.html` ต้องอยู่เครื่องเดียวกันถึงจะเห็นออเดอร์เดียวกัน
- ⚠️ กด "ล้างข้อมูลการท่องเว็บ" แล้วออเดอร์หายด้วย

**แนะนำ:** สิ้นวันกด **⬇️ ออกรายงาน CSV** เก็บไฟล์ไว้ก่อนล้างข้อมูล

> ถ้าอยากให้ลูกค้าสั่งจากมือถือตัวเองแล้วเข้าจอครัวได้ ต้องใช้ฐานข้อมูลกลาง
> (เช่น Supabase — ฟรี ไม่ต้องเขียน backend) แก้แค่ `store.js` ไฟล์เดียว
> เพราะทุกหน้าเรียกผ่าน `DB.xxx()` ไม่ได้ยุ่งกับ localStorage ตรง ๆ
